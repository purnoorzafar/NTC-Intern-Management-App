# NTC Intern Management App

An Android-based **Intern Management and Task Tracking Application** developed during my internship at **National Telecommunication Corporation (NTC)**. The application is designed to simplify the management of interns, task assignments, deadlines, task progress, and completion tracking through a simple and user-friendly mobile interface.

## 📱 Project Overview

The NTC Intern Management App provides a centralized platform where **supervisors can manage interns and assign tasks**, while **interns can view, start, and complete their assigned tasks**. The system helps improve communication between supervisors and interns and provides a structured way to monitor internship activities.

## ✨ Main Features

### 👨‍💼 Supervisor Module

* Supervisor account registration and login
* View registered interns
* Assign tasks to specific interns
* Add task title and description
* Set task deadlines
* Monitor assigned tasks
* View task status and progress
* Review completed tasks
* Provide feedback to interns
* Approve or reject submitted tasks

### 👨‍🎓 Intern Module

* Intern account registration and login
* View assigned tasks
* View task descriptions and deadlines
* Start assigned tasks
* Update task progress
* Mark tasks as completed
* Submit completed work for supervisor review
* View supervisor feedback

## 🗄️ Database

The application uses **SQLite** for local data storage.

The database manages:

* Intern and supervisor accounts
* User roles
* Task information
* Task assignments
* Deadlines
* Task status
* Supervisor feedback

## 🛠️ Technologies Used

* **Kotlin** – Application programming
* **Android Studio** – Android development
* **XML** – User interface design
* **SQLite** – Local database
* **Android SDK** – Application development and testing
* **Git & GitHub** – Version control and project hosting

## 🔄 Application Workflow

**Supervisor:**
Login → View Interns → Create Task → Select Intern → Set Deadline → Assign Task → Monitor Progress → Review Submission → Give Feedback

**Intern:**
Register/Login → View Assigned Tasks → Start Task → Work on Task → Mark Completed → Submit → Receive Feedback

## 🎯 Purpose

The main purpose of this project is to provide a simple digital solution for managing internship activities. Instead of maintaining tasks and progress manually, supervisors can use the application to assign and monitor work, while interns can easily keep track of their responsibilities and deadlines.
